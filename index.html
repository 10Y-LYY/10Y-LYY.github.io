About Us

关于我们

10Y·灵逸云科技是一家位于郑州的技术团队，2024 年成立。我们做的东西偏底层：一套操作系统，一个智能硬件平台，还有把开发流程搬到手机上的工具。

  • 01成立于 2024 年，总部在郑州
  • 02做操作系统、硬件平台与开发者工具
  • 03核心产品 10Y OS 与 HY 由团队自研
  • 04开源项目以 MIT 协议发布

团队十七个人，大部分是工程师。习惯先把问题弄清楚，再动手写代码；产品做完自己也天天用，遇到问题就改。灵逸 MB 就是我们把自己需要的工具做出来、再开放出去的一个例子。代码、文档和更新记录都放在公开的地方，谁都能看。

LingYi MB / Open Source

灵逸 MB，把开发板
装进口袋

以前要给 micro:bit 写程序，得开电脑、打开 MakeCode、把 .hex 拖进盘符，再用串口工具看输出。灵逸 MB 把这一整套流程放进安卓手机：连上板子就能写、能刷、能看实时数据。

下载与使用说明 → 开发者接口文档
01 / DISPLAY

LED 点阵与图案

在手机上编辑 5×5 点阵，实时推送到开发板显示。

02 / SOUND

声音与旋律

音调、节拍与自定义旋律，边写边听效果。

03 / SENSOR

传感器读数

加速度、温度等数据以图表形式实时呈现。

04 / INPUT

A/B 按键

远程触发按键事件，调试交互逻辑更方便。

05 / RADIO

无线指针

用手机充当无线输入设备，控制板载指针。

06 / FLASH

固件刷写

OTG 直连，一键把 .hex 刷进 micro:bit。

07 / SIM

悬浮窗模拟器

悬浮窗里模拟开发板，不连硬件也能预览。

08 / SCRIPT

指令编排

把常用操作排成序列，一次触发多条指令。

09 / GAME

互动小游戏

内置小游戏，用手机直接和开发板互动。
